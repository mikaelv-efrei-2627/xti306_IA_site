TP3 - Utiliser un LLM

Auteur·rice

Mikaël Valot

Le TP3 utilise un vrai LLM : Qwen3 1.7B, un petit modèle de 1,7 milliard de paramètres. Le notebook s’exécute sur Kaggle, qui prête gratuitement des GPU, mais vous l’éditez dans PyCharm, comme d’habitude. Si Kaggle ne fonctionne pas, le notebook peut aussi s’exécuter sur votre ordinateur, plus lentement (voir la fin de la page).

1 Récupérer le TP

  1. Cliquez sur ce lien d’invitation pour créer votre repository
  2. Cliquez sur “Accept assignment” puis “Open repository”
  3. Copiez l’URL de votre nouveau repository GitHub, et ouvrez-le dans PyCharm
  4. En cas de problème d’accès, suivez la procédure décrite au TP1 pour vous authentifier avec un token.

2 Créer son compte Kaggle (une seule fois)

  1. Créez un compte sur kaggle.com.
  2. Dans Settings, vérifiez votre compte avec votre numéro de téléphone (Phone verification). Sans cette étape, Kaggle ne vous donne accès ni aux GPU, ni à Internet.
Note

Kaggle donne environ 30 heures de GPU par semaine. Le compteur ne tourne que lorsque la session est active : pensez à l’arrêter à la fin du TP.

3 Démarrer une session Kaggle

  1. Sur Kaggle, cliquez sur Create, puis New Notebook. Ce notebook vide ne sert qu’à démarrer une machine.
  2. Dans le panneau de droite, Session options :
    • Accelerator : choisissez GPU T4 x2 ;
    • Internet : activez Internet on, pour pouvoir télécharger le modèle.
  3. Dans le menu, cliquez sur Run, puis Kaggle Jupyter Server.
  4. Dans le panneau qui s’ouvre, copiez le lien VS Code Compatible URL. Il contient déjà votre jeton d’accès : ne le partagez pas.

4 Connecter PyCharm à Kaggle

  1. Dans PyCharm, ouvrez le notebook tp3_llm.ipynb.
  2. Menu Tools, puis Add Jupyter Connection. Choisissez Connect to Jupyter server using URL, et collez le lien copié sur Kaggle.
  3. En haut du notebook, choisissez ce serveur dans la liste des serveurs Jupyter.
  4. Exécutez les deux premières cellules : la seconde doit afficher GPU NVIDIA : Tesla T4.

Le fichier du notebook reste sur votre ordinateur, dans votre repository : seul le calcul se fait sur Kaggle. Pensez à faire vos commits comme d’habitude.

AvertissementLa session s’arrête

Kaggle arrête la session quand elle reste inactive trop longtemps, ou quand vous fermez l’onglet Kaggle. Le serveur change alors d’adresse : redémarrez la session, copiez le nouveau lien, et reconnectez PyCharm. Il faut aussi réexécuter les cellules depuis le début, car le modèle n’est plus en mémoire.

5 Si la connexion PyCharm ne fonctionne pas

La connexion depuis PyCharm est une fonctionnalité récente de Kaggle, qui ne marche pas sur toutes les installations. Dans ce cas, travaillez directement dans le navigateur :

  1. Sur Kaggle, menu File, puis Import Notebook : choisissez le fichier tp3_llm.ipynb de votre repository.
  2. Vérifiez les Session options (GPU et Internet), puis exécutez le notebook sur Kaggle.
  3. À la fin, menu File, puis Download Notebook. Remplacez le fichier tp3_llm.ipynb de votre repository par celui-ci, puis faites votre commit.

6 Solution de repli : exécuter le notebook sur votre ordinateur

Sans Kaggle, le notebook s’exécute sur votre ordinateur, s’il a au moins 8 Go de mémoire vive. Le modèle est le même : seule la vitesse change.

  1. Ouvrez requirements.txt, et cliquez sur “pip update from requirements.txt”, comme au TP1.
  2. Ouvrez le notebook tp3_llm.ipynb, et exécutez les cellules dans l’ordre. La cellule qui charge le modèle le télécharge depuis Internet (environ 4 Go) : comptez quelques minutes.
Astuce

Le modèle n’est téléchargé qu’une fois, puis gardé sur le disque. Pour ne pas attendre pendant la séance, exécutez les cellules jusqu’au chargement du modèle avant le TP, chez vous.

Le notebook utilise automatiquement le GPU de votre ordinateur s’il en a un (NVIDIA, ou Mac récent), et sinon le processeur (CPU) : c’est beaucoup plus lent, mais suffisant pour le TP.
