1 Le principe

Le modèle a lu « le chat boit du ». Il a calculé une probabilité pour chaque token du vocabulaire : en voici 7. Pour écrire la suite, on tire au hasard un token selon ces probabilités.

La température modifie les probabilités avant le tirage :

  • basse : le token le plus probable écrase les autres ;
  • 1 : les probabilités calculées par le modèle, sans changement ;
  • haute : les probabilités se rapprochent, les tokens improbables sortent plus souvent.

le chat boit du ___

Tirages : 0

Changer la température efface les tirages.

2 À tester en cours

  1. Température 1 : cliquez 3 fois sur Tirer 20 tokens. Le nombre de « lait » est-il toujours le même ? Est-il proche de la probabilité affichée ?
  2. Température 0 : tirez 20 tokens. Que se passe-t-il ? Pourquoi dit-on que la réponse est alors reproductible ?
  3. Température 2,5 : tirez 20 tokens. Quels tokens apparaissent, qui ne sortaient jamais à température 1 ?
  4. Vous développez une application qui extrait la date et le montant d’une facture. Quelle température choisissez-vous ? Et pour un générateur de slogans publicitaires ?
